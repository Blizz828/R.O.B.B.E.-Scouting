MAIN API:
─────────

Three functions to remember:

  1. await globalStorageAdapter.setSharedValue('key', value)
     → Set data (syncs to all users)

  2. const data = await globalStorageAdapter.getSharedValue('key')
     → Get data from server

  3. globalStorageAdapter.onValueChange('key', callback)
     → Listen for updates from other users
